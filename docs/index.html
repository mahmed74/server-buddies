Install

  
Script tag (any website, no build step) — <script src="https://unpkg.com/server-buddies"></script> exposes window.ServerBuddies and registers the <server-buddy> element.

  
npm — npm i server-buddies, then import { createBuddy } from "server-buddies" or import { ServerBuddy } from "server-buddies/react". Styles are injected automatically; import server-buddies/style.css and pass injectStyles: false if your CSP forbids inline styles.


  
Options

  
Every option works as a createBuddy() option, a React prop, and (kebab-cased) a <server-buddy> attribute.

hang"rope"rope · chain · spring · thread · balloon · none. Each has its own physics.

      
position"top-right"top- or bottom- + left / center / right. Bottom positions perch (no tether).

      
accessory"auto"auto · none · nightcap · partyhat · crown · glasses · shades · headphones · santahat · witchhat · pumpkin

      
colorper characterMain body colour (hex). Darker/lighter shades are derived. Use colors to override main, dark, light, shell, screen, balloon individually.

offset{ x: 28, y: 0 }Distance from the chosen edge in px.

Methods

  
createBuddy() returns a handle. In React, put a ref on <ServerBuddy> for the same methods.

  

    
MethodWhat it does

    
      
say(text)Show a speech bubble.

      
setMood("happy" | "curious" | "down")Change mood. down shows X eyes, smoke and a red LED.

      
celebrate() / panic()Confetti burst / red alarm glow, with a swing and a line of speech.

      
flinch() / pass() / nod()Small reactions: a wince, an LED flash, a nod.

      
nervous(on)Jitter and sweat while something risky is in progress.

      
boop()Same as a click.

      
sleep() / wake()Force the sleeping state, or wake up.

      
show() / hide()Toggle visibility without destroying it.

      
update(options)Apply new options (rebuilds the buddy, keeps its mood).

      
destroy()Remove it and every listener and timer.

    
  


  
Example: react to a status check


const buddy = ServerBuddies.createBuddy({ character: "server", lookAt: "#check-btn", watchInput: "#url" });

async function check(url) {
  buddy.say("Here we go!");
  buddy.nervous(true);
  const res = await fetch("/api/check?url=" + encodeURIComponent(url)).then(r => r.json());
  buddy.nervous(false);
  buddy.setMood(res.ok ? "happy" : "down");
  res.ok ? buddy.celebrate() : buddy.panic();
}


  
FAQ

  
How do I add an animated mascot to my website?

  
Add <script src="https://unpkg.com/server-buddies"></script> and call ServerBuddies.createBuddy({ character: "robot" }). Use the configurator above to generate the exact snippet.

  
Is there a React or Next.js component?

  
Yes. npm i server-buddies, then import { ServerBuddy } from "server-buddies/react". It includes "use client" so it works in the Next.js App Router, and it renders nothing on the server.

  
Can I react to my app's state, like an error or a finished task?

  
Yes. Call setMood("down"), celebrate(), panic() or say("…"), or pass mood and outcome props in React.

  
Is it free?

  
Yes, MIT licensed with zero dependencies. See the source on GitHub or the package on npm.


  
Accessibility & performance

  
The buddy is a real <button> with an aria-label. It honours prefers-reduced-motion (physics and animations are off, speech bubbles stay), is hidden when printing, and does nothing during server-side rendering. Idle work is one 1 s timer; pointer handling is passive. ~12 kB gzipped, zero dependencies.
